# ふしぎな迷宮図鑑 🌿

子供向けの「探索 × 生き物収集」ゲームを、趣味と学習のために少しずつ制作します。公開・収益化は当面考慮しません。

## 開発方針
- 小さく完成させ、開発を休んでも気軽に再開する
- ゲームの楽しさを確認しながら機能を追加する
- ゲームロジックと描画・図鑑の記録を適度に分離する

## 現在の試作（v1.1 ビジュアル改善候補）
- 毎回ランダムに生成される森の部屋と通路
- 矢印キー / WASD / 画面ボタンで移動
- 5種類の生き物から、ひとつの森で3種類を発見（調査で見つかる生き物もいます）
- 発見済みを図鑑で確認（未発見は「？？？」）
- 発見状況はブラウザのlocalStorageへ保存
- 「別の森へ」で新しい地形と配置を生成

- 森・図鑑・おうち・発見モーダルで共通の生き物イラストを表示
- 木々と草花の森、木の家、見開きの図鑑で画面を区別
- おうちで発見した仲間をタップすると反応

イラストは `src/art/` の自作SVGです。外部画像サービスや追加ライブラリは不要です。
Phaserで使うSVGは `?url&no-inline` で取り込み、URI形式のインラインSVGによる読み込み失敗を防ぎます。

## 起動・テスト
Node.js / npm が必要です。

```bash
npm install
npm run typecheck
npm test
npm run build
npm run dev
```

本番ビルド: `npm run build`
