# モリルのふしぎ図鑑 🌿

森にくらす不思議な仲間「モリル」を探して、図鑑に記録し、おうちで交流する子供向けゲームです。趣味と学習のために少しずつ制作します。公開・収益化は当面考慮しません。

「モリル」は仲間たちの総称（仮称）です。個別の名前は、こけまる・ふわりん・きらぽん・しずくん・どんぐりんです。

## 開発方針
- 小さく完成させ、開発を休んでも気軽に再開する
- ゲームの楽しさを確認しながら機能を追加する
- ゲームロジックと描画・図鑑の記録を適度に分離する

## 現在の機能
- 毎回ランダムに生成される森の部屋と通路
- 地図の行き先をクリック・タップすると、壁を避けて移動。矢印キー / WASDでも移動可能
- 自分をタップ・Escで停止。「移動ボタンをつかう」を開けば、小さな4方向ボタンでも操作可能
- 「しらべる」は地図下のヒントの右側に配置。近くに調査対象があるときだけ押せる
- 5種類のモリルから、ひとつの森で3種類を発見（調査で見つかるモリルもいます）
- 発見済みを図鑑で確認（未発見は「？？？」）
- 発見状況はブラウザのlocalStorageへ保存
- 「別の森へ」で新しい地形と配置を生成

- 森・図鑑・おうち・発見モーダルで共通のモリルのイラストを表示
- 木々と草花の森、木の家、見開きの図鑑で画面を区別
- おうちで発見した仲間をタップすると反応
- 発見済みの仲間の「☆ えらぶ」で、お気に入りを1匹選択・変更できる
- 選択中の「⭐ はずす」でお気に入りを解除し、未選択に戻せる
- お気に入りは次回起動時にも復元。カードを触ったときの反応とは独立している
- キャラクターはマス間をなめらかに歩き、到着してから発見・歩数を判定
- お気に入りを選んで森へ出発すると、ヒント枠に顔と名前が登場し、その子らしい言葉で応援
- 応援は7歩ごとに変わり、近くに調査ポイントがある場合は調査の案内を優先

保存できない環境では、その画面を開いている間だけお気に入りを覚えます。お気に入り未選択でも、従来のヒントで探索できます。

イラストは `src/art/` の自作SVGです。外部画像サービスや追加ライブラリは不要です。
Phaserで使うSVGは `?url&no-inline` で取り込み、URI形式のインラインSVGによる読み込み失敗を防ぎます。

## 起動・テスト
Node.js / npm が必要です。

```bash
npm install
npm run typecheck
npm test
npm run build
npm run dev
```

本番ビルド: `npm run build`
