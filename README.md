# モリルのふしぎ図鑑 🌿

未知の場所を探索し、不思議な仲間「モリル」を発見するゲームです。現在の森・図鑑・おうちは初期実装で、収集や交流は探索を支えるサブ要素です。趣味と学習のために少しずつ制作します。公開・収益化は当面考慮しません。

「モリル」は仲間たちの総称（仮称）です。個別の名前は、こけまる・ふわりん・きらぽん・しずくん・どんぐりんです。

## 開発方針
- 小さく完成させ、開発を休んでも気軽に再開する
- ゲームの楽しさを確認しながら機能を追加する
- ゲームロジックと描画・図鑑の記録を適度に分離する

## ステージ1・小川と倒木の確認版
起動後の「主観視点の試作へ」、または `/?view=first-person` で開きます。既存の俯瞰探索は通常のURLに残しています。

- 矢印キー／W・Sで前進・後退、左右キー／A・Dで90度の方向転換、Q・Eで視点を変えずに左右へ移動。画面下の6ボタンでも1回ずつ操作できます
- 画面上の方角テキストと地図の見出し・凡例・記録マス数は表示せず、地図と現在地の矢印で位置と向きを確認します。読み上げ用の地図説明は維持します
- 足跡は地面の模様として描画。通り過ぎたり、そのマスに立ったりしても、画面に貼り付いた足跡は出ません。足元の調査は引き続き可能です
- 歩いた道・倒木と現在の向きを自動マップに記録。隣接した小川も記録しますが、未探索の道・渡河地点・モリルの位置は先に表示しません。ミニマップからの移動指定はありません
- 開始地点から北へ1歩で、正面の大きな足跡を調査可能。「調べる」またはSpaceで、大きさや指の形を観察します
- 道を進むと川辺へ出て、対岸の木々の間にしっぽが見えます。短い目撃中は移動を止め、図鑑を開くと演出も一時停止します
- 目撃は5.2秒。大型モリルは対岸を右から左へ横切り、太い付け根から細い先端へ続く尾が、手前の幹や枝葉に隠れながら通過します。奥へ移動して縮む演出は使いません。今回はティラノ系の重量感と動きを確認するコード描画で、全身や完成素材・効果音は未制作です
- 小川は見通せますが、そのまま歩いて渡ることはできません。川沿いに進むと一見行き止まりの倒木があり、幹の続く方向を向くと対岸への道になります
- 足跡・小川・倒木を「調べる」またはSpaceで観察可能。調査・アイテム・フラグ解除をしなくても、気づけば倒木をそのまま渡れます
- 対岸へ渡った後も川辺まで進め、振り返ると先ほどの岸と足跡の道が見えます。往復も可能です
- 目撃後の「目撃地点から再生」で同じ演出を再確認。「最初から」で地図・調査・目撃を初期化します
- PC・横向きタブレットでは主観画面の右に地図、幅700px以下では下に小さく配置します
- 地図直下の文章は一度に一つ。移動中は短い気配や案内、調べたときは特徴を1〜2文で表示します。調査結果は自動で消さず、次に移動・調査するまで残します（方向転換・図鑑の開閉では維持）。通れない場所での反応と目撃は優先します
- 幅700px以下では本文を画面幅で読みやすく表示し、主観画面には重ねません。しっぽの目撃中は映像を主役にし、終了後に短い案内だけを表示します

**一本道の導線を確認する短い版で、ステージ1の完成版ではありません。** 描画はPhaserによる仮の疑似3Dで、画像生成素材や新種の全身デザインは含みません。今回は倒木を渡って対岸の川辺に着くまで。大型モリルとの出会い・発見登録はまだ追加せず、図鑑・お気に入りの保存値も変更しません。既存探索の発見モーダルは維持します。

同じWi-Fiの端末から確認する場合は `npm run dev -- --host 0.0.0.0` を使い、表示されたNetworkのURLの末尾に `/?view=first-person` を付けます。信頼できるプライベートネットワーク内だけで使用し、ルーターのポート開放は不要です。

## 現在の機能
- 毎回ランダムに生成される森の部屋と通路
- 地図の行き先をクリック・タップすると、壁を避けて移動。矢印キー / WASDでも移動可能
- 自分をタップ・Escで停止。「移動ボタンをつかう」を開けば、小さな4方向ボタンでも操作可能
- 「しらべる」は地図下のヒントの右側に配置。近くに調査対象があるときだけ押せる
- 5種類のモリルから、ひとつの森で3種類を発見（調査で見つかるモリルもいます）
- 発見済みを図鑑で確認（未発見は「？？？」）
- 発見状況はブラウザのlocalStorageへ保存
- 「別の森へ」で新しい地形と配置を生成

- 森・図鑑・おうち・発見モーダルで共通のモリルのイラストを表示
- 木々と草花の森、木の家、見開きの図鑑で画面を区別
- おうちで発見した仲間をタップすると反応
- 発見済みの仲間の「☆ えらぶ」で、お気に入りを1匹選択・変更できる
- 選択中の「⭐ はずす」でお気に入りを解除し、未選択に戻せる
- お気に入りは次回起動時にも復元。カードを触ったときの反応とは独立している
- キャラクターはマス間をなめらかに歩き、到着してから発見・歩数を判定
- お気に入りを選んで森へ出発すると、ヒント枠に顔と名前が登場し、その子らしい言葉で応援
- 応援は7歩ごとに変わり、近くに調査ポイントがある場合は調査の案内を優先

保存できない環境では、その画面を開いている間だけお気に入りを覚えます。お気に入り未選択でも、従来のヒントで探索できます。

イラストは `src/art/` の自作SVGです。外部画像サービスや追加ライブラリは不要です。
Phaserで使うSVGは `?url&no-inline` で取り込み、URI形式のインラインSVGによる読み込み失敗を防ぎます。

## 起動・テスト
Node.js / npm が必要です。

```bash
npm install
npm run typecheck
npm test
npm run build
npm run dev
```

本番ビルド: `npm run build`
