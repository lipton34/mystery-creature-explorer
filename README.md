# ふしぎな迷宮図鑑 🌿

子供向けの「探索 × 生き物収集」ゲームを、趣味と学習のために少しずつ制作します。公開・収益化は当面考慮しません。

## 開発方針
- 小さく完成させ、開発を休んでも気軽に再開する
- ゲームの楽しさを確認しながら機能を追加する
- ゲームロジックと描画・図鑑の記録を適度に分離する

## 現在の試作（v0.3 開発中）
- 毎回ランダムに生成される森の部屋と通路
- 矢印キー / WASD / 画面ボタンで移動
- 生き物「こけまる」「ふわりん」「きらぽん」を発見
- 発見済みを図鑑で確認（未発見は「？？？」）
- 発見状況はブラウザのlocalStorageへ保存
- 「別の森へ」で新しい地形と配置を生成

※ 生き物・背景の絵は仮素材です。地形生成のビルドと実際の操作は確認待ちです。

## 起動・テスト
Node.js / npm が必要です。

```bash
npm install
npm run typecheck
npm test
npm run dev
```

本番ビルド: `npm run build`
