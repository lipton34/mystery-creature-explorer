# ふしぎな迷宮図鑑 🌿

子供向けの「探索 × 生き物収集」ゲームを、趣味と学習のために少しずつ制作します。公開・収益化は当面考慮しません。

## 開発方針
- 作業を小さく区切り、いつでも再開できるようにする
- 初期段階では接近による発見、後から発見条件を拡張する
- ゲーム性と見た目は実際に遊んでから段階的に改善する

## v0.2 図鑑機能（動作確認前）
- 3種類の生き物「こけまる」「ふわりん」「きらぽん」が出現
- 近づくと発見し、図鑑へ記録
- 「ずかんをみる」で発見済みの生き物の名前と説明を確認
- 未発見の生き物は「？？？」として表示
- 発見状況はブラウザに保存（v0.1の「こけまる」の発見記録を引き継ぐ）
- 「別の森へ」で各生き物の位置を再抽選

※ フィールドの地形はまだ固定です。図鑑内の絵文字は仮素材です。

## 動かし方
Node.js が必要です。

```bash
npm install
npm run build
npm run dev
```

表示されたURLをブラウザで開いてください。
