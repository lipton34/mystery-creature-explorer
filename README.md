# ふしぎな迷宮図鑑 🌿

子供向けの「探索 × 生き物収集」ゲームを、趣味と学習のために少しずつ制作します。公開・収益化は当面考慮しません。

## 開発の方針
- 開発を休んでも簡単に再開できるよう、作業を小さく区切ります
- 生き物を見つける方法は将来増やせる設計にします
- 最初から戦闘や育成を作り込まず、発見の楽しさを試します

## v0.1 試作
- 森のフィールドを表示（今は固定の長方形。生き物の位置はランダム）
- 矢印キー / WASD / タッチボタンで移動
- 生き物「こけまる」に近づくと発見
- 図鑑登録の状態をブラウザに保存（図鑑画面は今後追加）
- 「別の森へ」で生き物の配置を再抽選

## 動かし方
Node.js と npm が必要です。

```bash
npm install
npm run dev
```

表示されたURLをブラウザで開いてください。

型チェックと本番用ビルド:

```bash
npm run build
```
