# ステージ1「木漏れ日の小川」道順・演出案 v1

作成日: 2026-10-18  
状態: ユーザー承認済みの設計案。35歩の主経路・寄り道・仮イベントを初回実装。背景・音・全身デザインは最終素材ではなく、歩数・間隔は体験後に調整する。PR #21は未マージのまま保留。

## 1. 方針

- 主軸は探索と未知の大型モリルの発見。戦闘・育成・装備・ランダム生成は追加しない。
- 世界樹の迷宮は主観視点、見通し、道の組み立ての参考。自動マップと明るい森の方向性は維持する。
- 音 → 生き物の気配 → 川の先の姿 → 渡河 → 全身の発見、の順で情報を増やす。
- 基本は一本道。任意の観察用の短い寄り道を1か所だけ設ける。倒木探しのための迷路や条件解除は増やさない。
- ステージ全体の景色を通常探索の土台にする。イベント開始で別の背景へ切り替えない。
- この案の35歩は規模の初期値であり、完成版の長さ・所要時間を保証するものではない。体験が短ければ、景色や判断の変化を伴う区間を調整し、同じ道を単に水増ししない。

## 4. 区間ごとの演出

### S〜A: 最初の6歩

- 真っすぐな道。道の先に明るい木漏れ日が見え、操作の説明文を繰り返さなくても進める構図。
- 木の幹や草を近景、奥の木々を遠景にして、数歩でも進んだ実感を作る。
- 最初から遠い川やモリルを見せない。環境音と景色が中心。

### A: 大きな音

- 初回進入時、奥のほうから低い衝撃音。画面の揺れは0.3〜0.5秒程度の候補で、強さは実機で調整する。
- 主役は音と振動。文章は必要なら「……奥で、大きな音がした。」の1文だけ。
- 原因や「木が倒れた」とは断定しない。鳴き声や姿も同時に出さない。
- 操作を長時間止めない。揺れ抑制時はカメラを動かさず、音を消していても短い文章で出来事が分かるようにする。
- 振動は画面演出を指す。端末のバイブレーションは今回追加しない。

### C〜P: 足跡の任意観察

- Cから左の小空間に大きな足跡が一部見える。2歩で近づけ、同じ道を2歩戻れる。
- 調べると「靴ふたつ分の足跡。丸い指のあとが三つある。」程度。
- 調べなくても先へ進める。鳴き声や目撃の発生条件にはしない。
- ここに別の自動イベントやアイテムを追加しない。

### D: 鳴き声

- Aから8歩、複数の角を曲がったあとに初回だけ発生。
- 大きな音とは別の、低い生き物の声。威嚇や襲撃にはせず、存在と大きさの想像を促す。
- 対岸の奥から聞こえる設計。文を添える場合は「木々の奥から、低い鳴き声が響いた。」程度で、姿や正体は断定しない。
- Aの衝撃を繰り返したり、2度目の強い画面揺れを足したりしない。

### E〜F: 川が見える → 自分で近づく → 目撃

- Eに近づく段階で、進路右側の木の間に水面のきらめきを見せる。Eで右を向くと正面に川が見える。
- 水面は通常背景の一部。Eでは待っていても目撃を起こさない。
- Eから東へ1歩でFへ。川辺に立ち、対岸を向いているときだけ目撃を始める。横移動で入った場合も、見ていない向きで勝手に再生しない。
- 背景・木々の配置・水面は開始前後で変えず、木の後ろのモリルだけが動く。太い付け根から先端が順に見える左→右の通過。
- 正面を東とすると、画面左→右は北→南への移動。モリルはその後、対岸南側のG付近へ向かったと想像できる位置関係にする。
- 初回だけ発生。往復で繰り返さず、確認用の手動再生は本編イベントの条件から分離する。
- 既存と同様、図鑑中は演出を止め、閉じた後は続きから再開できる。

### F〜L〜H: 倒木を探して渡る

- Fから上流側の道が続くことを景色で示す。上流側へ向くと、木々の間に斜めの太い幹の一部が見える。
- 川沿い4歩のうち、後半で幹の伸びる方向が分かるようにする。いきなり足元に橋を出現させない。
- Lで道をふさぐように見える幹に近づき、川のほうへ向くと対岸まで続いていると分かる。
- 新しい折れ口や周囲の枝の散らばりで、Aの音との関連を示す。誰が倒したかは断定しない。
- 幹は最初から通行可能。音を聞く・調査する・目撃することを通行解除条件にしない。アイテムや修理操作も不要。
- まだ葉が落ちている演出は、短時間で到着した場合だけの追加候補。長く寄り道しても「ずっと倒れた直後」の描写を繰り返さない。
- Hでは振り返ると、渡った幹と元の岸が見える。別の景色として孤立させない。

### H〜G: 全身との出会い

- 渡河直後に全身は出さない。10歩と曲がり角を挟み、尾の目撃との間を取る。
- 新しい自動イベントは増やさない。木々が視界を遮り、Mで明るい空間の一部が見えるという背景の変化で期待を作る。
- Gから先の小さな開けた場所に、ティラノ系の巨大モリルがいる。頭・後ろ脚・尾の全体が初めてつながる。
- 木との比較、立ち姿、控えめな動きで大きさと格好よさを見せる。こちらへ襲いかかる、戦闘に入る、逃走を強制するといった展開にはしない。
- 発見をステージ1の到達点とする。発見登録の扱いと帰還画面は別途設計し、ここでは未確定。

## 5. 背景制作の単位

| 制作単位 | 主な場所 | 共通にするもの | その場所に必要なもの |
|---|---|---|---|
| 明るい森の道と曲がり角 | S〜D、H〜M | 地面・草・幹・樹冠・光の色 | 見通しと道の形、入口の開放感 |
| 足跡の小空間 | P | 森の道の素材 | 地面に固定した足跡 |
| 川沿いと見晴らし | E〜F〜L、H | 水面・岸・遠景の森・幹 | 見える範囲、目撃の遮蔽物、対岸との対応 |
| 倒木の渡河地点 | L〜H | 両岸と川沿いの素材 | 折れ口・幹の上面・歩ける幅・向きを変えた見え方 |
| 発見の開けた場所 | M〜G | 森の地面・木々・光 | 全身の立ち位置、木との大きさ比較 |

これは完成画像の枚数を示す表ではない。全マス・全方角を別々の完成イラストにする方式は採らず、共通素材で通路と角を構成する方法を先に検証する。現在の川辺一場面用の平面画像だけで、全方向が破綻なくつながると仮定しない。

## 6. 実装する場合の順番

1. このマップとイベントの間隔をユーザーが確認・調整する。
2. 仮描画で通行図を置き換え、A/D/F/Gの初回トリガーと簡素な仮演出を検証する。音声はプレイヤー操作後に有効化し、無音でも出来事が伝わるようにする。
3. 入口の直線＋一つの曲がり角で、接近・方向転換・逆向きへの復帰まで、通常背景がつながる構成を検証する。
4. 同じ素材・光・遠近感を使って、川沿い・倒木・対岸をつなぐ。
5. その通常背景に、尾と全身のイベント用素材を重ねる。イベントだけ別の背景にしない。

画像の量産・戦闘の追加・既存PRのマージは、この設計資料を作る作業には含めない。

## 7. 確認したいこと

- 入口6歩 → 音 → 8歩と曲がり角 → 鳴き声 → 3歩と角 → 川 → 1歩 → 目撃、の間隔。
- 足跡の2歩の寄り道を残すか。必須にはしない案。
- 倒木まで川沿い4歩、渡河後10歩で全身、という後半の長さ。
- 最後にモリルへ近づける距離・発見後の終わり方は次の設計項目。今の段階で追加の遊びを積み上げない。
