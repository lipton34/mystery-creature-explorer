# 仕様メモ（暫定）

## コンセプト
子供向けの「探索 × 生き物収集」ゲーム。探索の面白さと図鑑の収集、拠点での交流を両立する。

## v0.1〜v0.7（完了）
- 2Dの見下ろし探索、ランダム生成される部屋・通路
- 図鑑・拠点・発見記録の保存と生き物との交流
- 全5種類から1回の探索ごとに3種類を抽選
- 今回の森の全3種類を発見するとクリア。いつでも拠点に帰還できる

## v0.8（実装・動作確認待ち）
- 各森では抽選された3種類中1種類が草むらに隠れる
- 隠れている生き物の姿は調べるまで表示しない。草むらが目印になる
- 草むらと同じマス／隣接するマスで「しらべる」（ボタンまたはスペース／Enter）を押すと発見
- 移動だけでは隠れた生き物は発見できない
- 目に見える残り2種類は従来どおり同じマスに入ると発見
- 位置はすべて移動可能・到達可能な場所から決定
- 発見記録・探索別クリア判定は従来を維持

## 今後の候補
- 調査できる場所の見た目を増やす（木・石など）
- 「しらべる」操作のヒント、発見時の専用演出
- アイテムを使った生き物ごとの仲間化条件
- 拠点の交流や図鑑の見た目改善

## 設計
creatures.ts：全生き物。world.ts：マップ・抽選・発見判定。
visuals.ts：仮描画。collection.ts：通算図鑑。expedition.ts：探索ごとの進捗。main.ts：入力と表示。
