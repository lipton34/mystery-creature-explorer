# 仕様メモ（暫定）

## コンセプト
子供向けの小さなランダム探索＋生き物図鑑ゲーム。公開や収益化は目標にしない。
開発は中断・再開が自然にできるよう、小さく完成させて積み上げる。

## v0.1 実装範囲
- ブラウザで動く2D見下ろし型探索
- キーボード・画面ボタンによる上下左右移動
- 境界で移動を止める
- 生き物に隣接すると発見判定
- 一度の発見結果をローカルストレージに記録
- 森を再生成して繰り返し探索
- 仮の図形で主人公と生き物を描画（正式アセット未作成）

## 今後の候補（未確定）
- 部屋と通路を持つランダムマップ生成
- 複数生き物、発見図鑑画面、拠点でのふれあい
- 生き物ごとに異なる発見条件（調べる、アイテム、ミニゲーム等）
- 操作感・アニメーション・スマホでの遊びやすさの改善
- ローグライクの深さ、戦闘の有無は未決定

## 設計の意図
移動・フィールドの情報（world.ts）と発見記録（collection.ts）を分離。
新しい捕獲条件を作る場合は、既存の接近判定をそのまま増やさず
発見トリガーと仲間化条件を独立させる。
