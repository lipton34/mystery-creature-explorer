# 仕様メモ（暫定）

## ゲーム方針
未知のステージを探索して、新種のモリルに出会う体験を主軸にする。収集・図鑑・ふれあいはサブ要素。舞台は森に限定せず、名称も仮称。遊びやすさと幼児向けの絵柄は分けて考える。

## ステージ1の方向性と今回の確認範囲
- 舞台は小川が流れる明るく元気な森。木々の高さで姿を一部隠す。暗闇や鬱蒼とした雰囲気を探索の主因にしない
- 基本は一本道。川辺から対岸のモリルの一部を見て、渡りたい動機を作り、川沿いで渡れる倒木を見つける
- 一見道をふさぐ倒木の根元に近づき、向きを変えると川をまたぐ幹の続きを認識できる。歩ける面には木目、手前の断面には年輪を描く
- 水面は描画と視線を通し、移動だけを阻む。倒木は最初から歩ける。調査・アイテム・修理・目撃を通行条件にしない
- 足跡・小川・倒木に調査文を用意。ミニマップには歩いた幹と隣接した水辺を記録するが、未探索の対岸・倒木は先に明かさない
- 今回は対岸の川辺から元の岸を振り返るまでの短い導線確認。大型モリルの全身と発見・ステージ1の完成は次段階

## 主観視点の基礎仕様
- 初期版の目標はステージ1・2。ただし今回はステージ1制作前の短い体験試作
- 手作りの通路で前進・後退、90度の左右方向転換、向きを保つ左右の横移動。滑らかな視点遷移を行い、移動中の追加入力は受け付けない
- キーボードの既存操作は維持し、Q/Eを横移動に割り当てる。移動先計算を共有し、横移動の水際衝突でも正しい案内を表示
- 方角の常設テキストは不要。自動マップは説明文・見出し・記録数を表示せず、現在地と向きの矢印を残す。読み上げ用の位置・向きの情報は維持
- 足跡は床の模様として世界座標に固定し、床と同じ透視投影・遮蔽を適用する。現在マスに立った場合の画面固定描画は行わない
- 自動マップは歩いた床と接する壁、現在位置・向きを記録。未探索の床・モリル・目撃位置を先に表示しない。地図を押して移動する方式は使わない
- 大きな足跡を足元か正面で調べ、大きさ・形・歩幅から想像する。調査しなくても目撃へ進める
- 川辺の見晴らしで対岸のしっぽが横切り、木々の向こうに隠れる。全身や新種は未制作
- 映像の方向性は冒険ゲーム寄り＋手描きの温かさ。最初の大型モリルはティラノ系で、大きさへの驚きとかっこよさを優先。太い付け根と先細りの尾、控えめな背の稜線を使い、巻き尾にしない
- 目撃は5.2秒、対岸と平行に右から左へ通過。奥へ遠ざかる・縮小・フェード消失は使わず、世界座標上の横移動と幹・枝葉の前景で隠す。頭と全身は見せず、付け根の接続部分だけを木陰に描く。揺れを抑える設定では尾の上下の揺れを止め、横移動は維持
- 目撃中は移動を一時停止。図鑑を開いた時間は演出・視点遷移から除外する
- ミニマップはPCでは主観画面の横、狭い画面では下へ。画面上への重ね表示はしない
- 探索のヒントと調査・目撃の反応文はミニマップ直下の同じ枠にまとめる。幅700px以下では地図を右寄せの120px幅、本文を画面幅で表示。文章を固定高で切ったり、主観画面に重ねたりしない
- 本文は一度に一つだけ。移動中は短い気配・案内、調査時は大きさや形など想像につながる特徴を1〜2文で表示。調査結果は時間で消さず、次の移動・調査まで維持し、方向転換・図鑑開閉では上書きしない。衝突・目撃の反応は優先する
- 同じ文章でDOMを更新せず、読み上げの重複も抑える。目撃中は映像を優先し、終了後だけ渡河先を探す短い案内へ切り替える。制作範囲の説明はフッターに残し、到着時の物語文には混ぜない
- 図鑑・お気に入りの保存値、既存探索の発見モーダルは維持。試作の状態は永続保存しない
- ランダム生成・周回前提、複雑な装置、見つからない理由を解明する条件、新種の大量追加、画像刷新は今回の範囲外

## v1.0 初期完成版候補（動作確認待ち）
- 森は緑を中心に自然な背景、拠点は暖かい木目調と家の装飾、図鑑は紙と本を思わせる配色・縁取りを用いる
- 画面切替で背景の配色も変えて、テキストに頼らず現在位置を認識できるようにする
- 画面外側の背景のみ切り替え、Phaserキャンバス自体は保持する
- アプリを開いた直後はおうち画面にする。初めての探索はおうちから出発
- 図鑑から「おうちへ」を押して直接おうち画面に遷移できる
- 図鑑の「もどる」は開く前の画面（森かおうち）に戻る
- 図鑑・おうち表示時もPhaserのキャンバスは取り外さず、縮小の不具合を防止
- マップ左上に固定のヒント/コメント表示エリア（探索中だけ表示）
- 近くに調査可能な対象があれば対象名と調査の案内を表示
- それ以外は探索の短いコメントを7歩ごとに切替。将来の同行生き物のセリフへ拡張可能
- 調査操作のボタンは通常はdisabled。調査対象が近ければ有効化して目立つ表示にする
- 発見時は画面中央のモーダルに生き物の名前、アイコン、図鑑登録状態を表示
- 3種類全発見時は発見モーダルを閉じた後、達成モーダルを表示
- モーダルは「つづける」で閉じ、表示中は探索入力を止める
- スマホ用の移動操作ボタン拡大・画面幅に合わせた表示
- 図鑑・拠点のオーバーレイ方式と保存形式は維持

## 初期完成版の条件

## お気に入り選択
- おうちで発見済みのモリルを1匹選択し、別の仲間へ変更できる。未選択のままでも出発可能
- カード本体は従来のタップ反応、別の「☆ えらぶ」ボタンでお気に入りを設定
- 選択中は星付きの状態を示し、おうちに顔・名前を表示
- 発見記録と別の保存キーに記録し、再起動や図鑑への往復・出発後も選択を維持
- 不正・未発見の保存値は未選択として扱う。保存不可の場合は現在の画面内で選択を保持し、案内を表示
- 選択中の星ボタンを「⭐ はずす」と表示し、再度押すと解除する。解除状態も保存し、発見記録は変更しない

## 探索中の応援
- ヒント枠はマップ下の独立した帯に配置し、地形・探検家・モリルには重ねない
- 出発時のお気に入りのモリルをヒント枠に顔・名前付きで表示する
- 5種類それぞれに3つの短い応援文を用意し、歩けた7歩ごとに切り替える
- 近くに調査ポイントがある場合は、応援文よりも調査案内を優先する
- お気に入り未選択なら顔・名前を表示せず、従来の5つのヒントを使う
- おうちでお気に入りを変更すると次の出発時に反映する。図鑑への往復では相手・探索状態を保持
- ヒント枠は森だけに表示し、調査・発見・クリアの判定や地形生成には影響しない

## 探索操作の省スペース化
- PC・タブレット・スマホ共通で、地図上の目的地をクリック・タップして道に沿って移動する
- 歩行は従来の1マス単位で行い、通常の発見・歩数・調査判定を通す。壁や到達できない場所は移動しない
- 1マスを160msで補間して歩き、影も追従する。発見・歩数は到着時に確定し、装飾的な上下動は動きを減らす設定で抑える
- 停止指示では現在の一歩だけを歩き終え、残りの経路を破棄する。入力された次の方向は1回分だけ保持し、歩行中の行き先変更は到着予定マスから経路を作り直す
- 歩行中のSpace調査は現在の一歩の到着後に行う。図鑑・おうちの表示中は発見モーダルを出さず、新しい森への出発では途中の歩行状態を破棄
- 目的地を枠で表示し、自分のタップ・Esc・キーボードの方向指定・調査・画面切替・発見・ウィンドウのフォーカス喪失で経路移動を中止
- 別の目的地を押すと経路を更新する。ドラッグやスクロールは新しい移動として扱わない
- 4方向ボタンは初期状態で折りたたみ、必要なときに開く。ボタンは48×44pxでクリック・長押し・キーボードに対応
- 「しらべる」はマップ下のヒント帯の右側。PCは幅116px、スマホは96px、どちらも高さ44px以上を確保
- 地図枠の縦横比を固定し、画面幅変更時に小さな地図が枠内に残る問題を防ぐ
