# 仕様メモ（暫定）

## コンセプト
子供向けの「探索 × 生き物収集」ゲーム。小さな完成形を重ね、遊びの楽しさを高める。Steamなどの配布は完成後に検討。

## v0.1〜v0.6
- 見下ろし型のランダムな森・移動・同じマスで生き物を発見
- 図鑑とlocalStorage保存、拠点への自由帰還、拠点での交流
- その森にいる全種類を発見したときのクリア演出

## v0.7（実装済み・動作確認待ち）
- 図鑑の登録対象を3種類から5種類に増やす
- 既存：こけまる、ふわりん、きらぽん
- 新規：しずくん（水色のしずく）、どんぐりん（どんぐりの帽子）
- 1回の探索では5種類から異なる3種類を等確率で抽選
- 生き物は通行可能・到達可能・位置の重複しないマスに置く
- 探索ごとの3種類すべてを発見するとクリア
- 累計の図鑑は5種類のまま。v0.6以前の登録データを引き継ぐ
- 新しい生き物にも拠点での交流メッセージを2種類用意

## 今後の候補
- 隠れた生き物や怪しい場所の調査、アイテムを使う発見方法
- 拠点の演出改善とイラスト制作
- 新しい地形・探索の仕掛け

## 設計
creatures.tsで全種類、world.tsで出現抽選と位置決定。
visuals.tsで仮の描画、collection.tsで図鑑保存、expedition.tsで探索ごとのクリア判定。
