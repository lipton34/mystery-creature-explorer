# 仕様メモ（暫定）

## コンセプト
子供向けの「探索 × 生き物収集」ゲーム。戦闘・育成は行わず、探す・見つける・集める・仲間と交流する楽しさを重視。

## v0.1〜v0.9 完了
- 2D見下ろし移動・ランダム生成の森
- 5種類から各探索3種類を抽選（通常2種類＋調査1種類）
- 草むら・切り株・石を調べて隠れた生き物を発見
- 発見記録を図鑑に保存。拠点で生き物をタップして反応を楽しむ
- 森からいつでも帰宅でき、3種類を発見するとクリア

## v1.0（実装・動作確認待ち）
- 探索の進捗と次の行動の案内をわかりやすく分離
- 調査できる場所の近くでボタンを強調
- 発見時に生き物アイコン・名前・新規図鑑登録か再会かのメッセージを表示
- 狭い画面でもヘッダー・操作ボタンを使いやすく調整
- ボタンにフォーカスしている場合のEnterキー動作を尊重し、スペースで調査
- 図鑑と拠点はゲーム画面に重ねる方式を維持（縮小の不具合を回避）
- 図鑑・探索・拠点の保存仕様や発見条件は変更しない

## 初期完成版の判定
`npm run typecheck`、`npm test`、`npm run build`の成功に加え、PCブラウザで全画面遷移と操作の手動検証を行う。
スマホ実機・Safari・異なるブラウザでの動作は公開前に別途検証。

## 将来
アイテムを使う発見条件、さらに多くの生き物、素材のビジュアル改善などはv1.0後に検討。
